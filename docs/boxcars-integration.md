# Boxcars integration contract

Replay Forge uses the `rrrocket` command line executable, which runs the Rust `boxcars` parser, behind a restricted Electron IPC boundary. A future native Rust helper should replace this JSON bridge for performance.

## Decoder installation

Download the Windows MSVC build from https://github.com/nickbabcock/rrrocket/releases and place `rrrocket.exe` in `tools/bin/` for development, or set the `REPLAY_FORGE_RRROCKET` environment variable to the binary path. The parser does not ship automatically in this release. The decoding process uses `--network-parse`.

## Current scope and accuracy

- Decodes with Boxcars and attempts to reconstruct frame-by-frame ball/car positions through replicated RigidBody states.
- Returns an explicit error for missing/unsupported network data instead of pretending real playback is possible.
- **Partial normalization:** actor-to-player names, team identity, rotation and arbitrary compression variants are not guaranteed to be resolved; no confident mechanic classification.
- If frame data is missing or no ball tracks can be reconstructed, decoder returns an error and the viewer remains on the previous track.
- The viewer demo is synthetic and always clearly labeled.
- No force estimates or mechanic indicators are generated by the decoder yet. Architectural overlay layers are designed to accept those eventually.
- Importing large replays can require substantial memory; a streaming/columnar decoder is the recommended next step.

## Event and overlay extension API

Normalized frames, events and detector overlays are separate concepts. Future detectors should produce a versioned structure:

```json
{"id":"event-184","type":"zapdash","time":32.1,"actorId":"car-42","confidence":0.84,"detector":"zapdash-v1","evidenceFrames":[960,961,962]}
```

Overlay systems should consume event records, not embed detector logic inside Three.js scene components.

## Important

**Raw network JSON does not mean a reconstructed match is fully reliable.** Replay actor ids can be reused and game patches can change replication schemas. Results should be validated against labeled replays and gameplay footage before enabling performance analytics.
